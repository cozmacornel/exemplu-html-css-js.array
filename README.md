# Exemplu Array JS

Un mic proiect demonstrativ care arată cum se lucrează cu array-uri în JavaScript (adăugare, ștergere, căutare, sortare). Ideal pentru începători.

## Funcționalități

- ✅ Afișează o listă de produse
- ✅ Adaugă produse noi în array
- ✅ Șterge produse din array
- ✅ Caută produse (filter)
- ✅ Sortează produse alfabetic
- ✅ Validează duplicate

## Metode Array folosite

- `push()` - adaugă elemente
- `splice()` - șterge elemente
- `filter()` - filtrează elemente
- `sort()` - sortează elemente
- `forEach()` - iterează prin array
- `includes()` - verifică existența

## Cum rulezi proiectul

Fără dependențe - deschide `index.html` în browser:
- Dublu-click pe fișier SAU
- Click dreapta → Open with Live Server (în VS Code)
